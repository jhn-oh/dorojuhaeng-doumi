# 휴대폰에서 연습 기록 받기

차량의 **휴대폰으로 보내기 → QR로 받기**를 누르면 인터넷 없이 결과를 읽을 수 있습니다. 새 회차의 요약에는 코스, 시간, 차량에서 관측한 신호와 복습 내용이 담깁니다. 이전 방식으로 저장한 회차는 당시의 점수 또는 보류 사유를 함께 보냅니다.

**휴대폰 연결하기**는 열린 모바일 브라우저에 기록을 전달합니다. Python 3.9 이상의 표준 라이브러리로 실행합니다. 실기기에는 휴대폰과 차량이 모두 접근할 수 있는 HTTPS 주소가 필요합니다. TLS를 종료하는 역방향 프록시 뒤에 서버를 실행하고 공개 주소를 `--public-url`로 지정합니다. 이 저장소에는 운영 서버가 지정되어 있지 않습니다.

```powershell
py -3 receiver/server.py --bind 127.0.0.1 --port 18771 --public-url https://수신서버주소
```

1. 주차 후 차량에서 **휴대폰으로 보내기 → 휴대폰 연결하기**를 선택하고 서버 주소를 입력합니다. 차량이 5분간 유효한 연결 QR을 표시합니다.
2. 휴대폰으로 QR을 찍고 기기 이름을 확인합니다. 차량에서 그 이름과 보낼 내용을 확인한 뒤 **이 휴대폰으로 보내기**를 누릅니다.
3. 휴대폰에 결과가 나타나면 **이 기록을 받았어요**를 누릅니다. 서버가 같은 개정번호의 수신을 확인한 뒤 차량에 완료가 표시됩니다. 재연습한 구간은 지난번과 이번 신호가 함께 표시됩니다. **텍스트 파일로 저장**을 누르면 현재 요약을 저장할 수 있습니다. 같은 탭을 새로고침하면 연결이 유효한 동안 기록을 다시 열 수 있습니다.

연결과 결과는 메모리에만 보관합니다. 차량과 휴대폰의 권한 토큰은 서로 다릅니다. 연결 만료는 생성 시점부터 5분이며 서버를 다시 시작하면 기존 연결이 종료됩니다. 취소된 전송은 다시 열 수 없습니다. 이미 읽거나 저장한 사본은 기기에 남을 수 있습니다.

## 같은 컴퓨터에서 재현

디버그 APK와 호스트 브라우저를 연결할 때 다음 명령을 사용합니다. 차량에는 `http://127.0.0.1:18771`을 입력합니다. localhost QR은 검증용 컴퓨터의 브라우저에서 열 수 있습니다.

```powershell
py -3 receiver/server.py
adb -s emulator-5580 reverse tcp:18771 tcp:18771
py -3 -m unittest discover -s receiver
```
