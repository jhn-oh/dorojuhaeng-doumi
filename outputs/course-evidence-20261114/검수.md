# 일원터널 유턴과 서울 도로 소통 사례

2026년 11월 14일 KST 기준. 검수한 앱의 에뮬레이터와 APK를 변경하지 않고 공단 공지·원본 약도, 지도 라우터, 서울시 공개 응답을 대조했다.

## 강남 A코스 유턴

강남시험장은 2023년 3월 8일 15시 49분에 A~D 코스 약도를 게시했다. A코스에서 대모산입구역R을 지나 일원터널R에 접근한 남행 경로가 북행으로 되돌아간다. 원본은 도식이며 실제 도로와 다를 수 있다는 설명을 포함한다. 공단의 현재 동영상 게시판도 A코스 영상을 직접 연결한다. 영상 게시 시각은 한국 시간 2020년 9월 21일이며 길이는 13분 54초다. [공단 공지](https://www.koroad.or.kr/main/board/9/87734/board_view.do) · [공단 JPG](https://www.koroad.or.kr/file/FileDown.do?atchFileId=FID00115200&fileSn=0&mtIdx=MN05010521) · [공단 A코스 영상](https://www.youtube.com/watch?v=VKMmgEs_1u0)

공단은 약도에 좌표를 싣지 않았다. 시험장 약도의 행정 지명과 ITS 영동대로·광평로 링크로 후보를 찾고, 지점 북쪽에서 남행 출발 및 북행 복귀 방향을 지정해 자동차 경로를 계산했다. OSRM의 유턴 단계 좌표는 **북위 37.485988°, 동경 127.075513°**다. OSRM은 561.2m·57.7초, Valhalla는 562m·102.267초이며 양쪽 모두 일원터널 부근에서 180도 방향을 바꾼다. 두 서버는 OpenStreetMap 자료를 이용하며, 이 길이는 지점을 확인하기 위한 짧은 왕복 구간 기준이다. 실차에서 현재 유턴 허용 시간, 적용 신호, 보조표지와 실제 차로를 확인한 기록은 없다. 출력 문구는 **강남시험장 A코스 약도의 일원터널 유턴 지점**으로 두고, 주차 중 도해와 현장 신호·표지 확인의 필요성을 안내한다. [OSRM 질의와 시각](./ilwon-osrm.meta.json) · [완전한 계산 결과](./ilwon-osrm.http) · [Valhalla 결과](./ilwon-auto.http)

## 실제 등록 코스의 소통 정보

서울시가 공식 공개한 2025년 3월 6일자 표준링크 매핑 XLSX를 다운로드해, 강남역 동쪽 테헤란로에서 올림픽공원 서쪽 올림픽로로 가는 앱의 8.709km 경로와 대조했다. 이미 진행 방향을 검수한 42개 표준링크 중 41개가 서울시 소통 서비스링크 17개에 들어간다. 매칭된 서비스링크의 구성 표준링크 모두가 이 경로에 속한다. 표준링크 `1230436901`은 매핑표에서 연결하지 못했다. 경로의 시작·끝 일부는 서비스링크 전체의 시작·끝과 정확히 일치하지 않을 수 있다. [서울시 공식 매핑표](https://data.seoul.go.kr/dataList/OA-15061/S/1/datasetView.do) · [도로·방향 대조](../course-routing-20261114/wide-roads/coverage-recheck.json)

**2026년 11월 14일 15시 07분 37초부터 42초까지**, 공개 샘플로 서비스링크 17개를 개별 조회했다. 17개 모두 요청한 링크와 같은 ID로 응답했다. 서울시가 반환한 속도는 **8.8~36.7km/h**다. 예를 들어 테헤란로 서비스링크 `1220028100`은 8.8km/h, 올림픽로 `1220029500`은 29.2km/h였다. 응답은 각 서비스링크의 속도·통행시간을 제공한다. 응답 행에 측정 시각·혼잡등급이 없어 위 시간은 **검수자가 조회한 시각**으로 표기한다. 한 번 저장한 수치는 현재 상태 또는 코스 전체 실시간 소요시간으로 재사용할 수 없다. [17개 서비스링크 전체 응답 대조](./route-traffic-comparison.json) · [서울시 API 명세](https://data.seoul.go.kr/dataList/openApiView.do?infId=OA-13291&srvType=A)

## 공식 정체 등급이 있는 별도 사례

서울시 실시간 도시데이터의 샘플은 광화문·덕수궁만 제공한다. 강남역을 지정한 샘플 요청도 광화문·덕수궁이 반환됐다. 해당 구역 도로소통 현황 시각은 **2026년 11월 14일 14시 55분**, 평균 **12km/h·정체**다. 포함된 세종대로 `1010018100`은 **시청앞교차로 → 청계광장, 북행 445m, 10km/h·정체**다. 이 구간 행에는 자체 측정 시각이 없다. 지역의 도로소통 현황 시각을 개별 차량 관측 시각으로 바꾸지 않는다. `XYLIST`에는 종점부터 시점 순으로 좌표 9개가 들어 있으므로 진행 방향 화살표를 그리려면 뒤집어야 한다. [공공데이터포털 소개·샘플 범위](https://www.data.go.kr/data/15146211/openapi.do) · [실제 조회 원본](./city-sample.http)

## 데이터 이용과 실행 환경

서울 열린데이터광장의 OA-13291 데이터셋은 출처표시 조건으로 상업적 이용과 변경을 허용하는 공공누리 제1유형이다. 서울시 실시간 도시데이터도 공공데이터포털에서 무료·공공누리 제1유형으로 안내한다. 앱과 제출물에 서울특별시와 데이터셋명을 명시한다. [도로 소통 정보 데이터셋](https://data.seoul.go.kr/dataList/OA-13291/A/1/datasetView.do) · [도시데이터 이용 조건](https://www.data.go.kr/data/15146211/openapi.do)

인증키는 데이터 이용허락과 별도다. 서울시 개발자 문서는 서비스 등록과 키 발급을 안내하고 샘플은 요청 인덱스 1~5로 제한한다. TOPIS는 안내 페이지에서 비영리 목적의 API 서비스 이용과 인증키 신청 절차를 설명한다. 공개 예제 키를 유료 앱의 상시 서비스에 쓸 수 있다는 약속·속도 측정시각 보장·서비스 수준 보장은 확인되지 않았다. 판매용 실시간 추천은 발급 용도를 확인한 운영 키와 새 응답을 사용해야 한다. 이번 작업은 등록 코스의 **조회 사례**와 별도 지역의 **공식 과거 정체 사례**를 보관했다. [서울시 API 이용 절차](https://data.seoul.go.kr/together/guide/useGuide.do) · [TOPIS 안내](https://topis.seoul.go.kr/refRoom/openRefRoom_4.do)
